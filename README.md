CosmicWatch V2 Project @ Rutgers University
--------------------------------------------

Officially, the v2 detector is outdated, but our project still uses the v2 plans.

import_data_py3.py is adopted from the import_data.py script, updated for compatibility with Python 3

data_collection_py3.py is a further edited version that notes the exact detector, date, and run time in the file name.
  This script can also be run for a set number of time (ie: can set to collect data for 5 minutes, and stop data collection after that)

Collecting data for each detector should be conducted using the data_collection_py3.py script
